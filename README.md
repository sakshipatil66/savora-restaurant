# Savor The Moment

REDESIGN AND POLISH THE ENTIRE RESTAURANT WEBSITE.

Use the following Dribbble restaurant design references as VISUAL INSPIRATION:

https://dribbble.com/search/shots/popular/animation?q=restaurant-website

IMPORTANT:

Do NOT copy any specific website, branding, text, images, or layout exactly.

Use the references only to understand the level of visual quality, animation, interaction, composition, typography, and premium restaurant presentation.

The final result must look like a professionally designed restaurant website created by an experienced UI/UX designer.

==================================================

1. OVERALL DESIGN DIRECTION

==================================================

Create a premium, cinematic, modern restaurant website.

Visual direction:

- High-end restaurant / fine dining aesthetic

- Cinematic food photography

- Full-width visual sections

- Elegant typography

- Strong visual hierarchy

- Sophisticated color palette

- Premium dark/cream/warm tones

- Subtle gold or warm accent color

- Clean spacing

- Editorial-style layouts

- Modern asymmetrical compositions

- Beautiful image cropping

- Subtle shadows

- Minimal borders

- Smooth transitions

- Premium micro-interactions

DO NOT make it look like:

- a generic template

- a basic food delivery website

- an AI-generated landing page

- a collection of random cards

- an overly colorful website

- a PPT-style website

Keep the design sophisticated and visually memorable.

==================================================

2. HERO SECTION

==================================================

Create a cinematic full-screen hero.

Use a professional high-resolution restaurant/food background image.

Hero should include:

- Restaurant logo/name

- Short premium tagline

- Strong headline

- Short description

- Primary CTA: "Reserve a Table"

- Secondary CTA: "Explore Menu"

Example:

"SAVORA"

"Where Flavor Meets Experience"

"An elevated dining experience crafted around exceptional ingredients,

thoughtful cooking, and unforgettable moments."

Buttons:

[Reserve a Table]

[Explore Menu]

Add small restaurant information:

PUNE • MAHARASHTRA

OPEN DAILY • 12 PM — 11 PM

Hero interactions:

- Slow image zoom effect

- Subtle parallax effect

- Text fade-up animation

- CTA hover animation

- Elegant page-load entrance animation

- Image overlay for readability

Do not make animations excessive.

==================================================

18. RESPONSIVENESS

==================================================

The website MUST be fully responsive.

Test layouts for:

1440px desktop

1280px desktop

1024px laptop

768px tablet

430px mobile

390px mobile

360px mobile

Fix:

- Horizontal scrolling

- Overlapping text

- Broken images

- Excessive whitespace

- Tiny text

- Broken buttons

- Navigation issues

- Incorrect image cropping

- Grid overflow

- Form overflow

Mobile must feel intentionally designed, not just a desktop layout squeezed smaller.
